# AI Onboarding Chatbot 🤖

A fast AI-powered onboarding chatbot built using Streamlit, LangChain, FAISS, and Groq LLM.

The chatbot answers user questions from company PDFs such as:
- Holiday lists
- Cafeteria menus
- Onboarding documents
- Internal resources

## Features
- Semantic Search using FAISS
- Groq LLM Integration
- Fast Response Time
- PDF-based Knowledge Retrieval
- Streamlit Web Interface

## Tech Stack
- Python
- Streamlit
- LangChain
- FAISS
- HuggingFace Embeddings
- Groq API

## Run Locally

```bash
streamlit run app.py
